# Developer Persona — Working Assumption

## Status

This is a provisional persona created because the official
PERSONA_BRIEF.md was not included in the starter repository.

It will be updated if the instructor provides additional requirements.

## Persona

The Kente Retail developer is responsible for deploying,
managing, and troubleshooting application workloads in the
sandbox AWS environment.

## Assumed Responsibilities

- Manage application EC2 instances.
- Access application artifacts stored in S3.
- Read application logs for troubleshooting.
- Start, stop, and restart development workloads.
- View relevant resource information.

## Assumed Restrictions

The developer should NOT:

- Create or manage IAM users.
- Modify IAM policies.
- Manage billing.
- Modify account-level settings.
- Access resources belonging to other learners.

## Least-Privilege Principle

Only permissions required to perform the responsibilities above
will be granted.
